# EPSILON-DELTA

```bash
The formal definition of a limit (or the epsilon-delta definition)
states that the limit of a function f(𝒙) as 𝒙 approaches 𝒂
is equal to 𝑳 if, for every tolerance ε > 0, there exists 𝒂
corresponding proximity radius δ > 0.
```

```bash
0 < |𝒙 – 𝒂| < δ, then |f(𝒙) – 𝑳| < ε
```
